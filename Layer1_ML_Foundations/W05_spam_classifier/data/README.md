# Dataset

This directory contains data for the spam classifier project.

## Dataset: UCI SMS Spam Collection

**Source:** [UCI Machine Learning Repository](https://archive.ics.uci.edu/ml/datasets/SMS+Spam+Collection)

**Description:**
- SMS messages in English
- 5,574 messages total
- Binary classification: Spam (747 messages) and Ham (4,827 messages)
- Original data collected by Tiago A. Almeida and José María Gómez Hidalgo
- Released for research and educational purposes

**How to obtain the dataset:**

The dataset is downloaded automatically when you run the notebook or the training script.
It will be saved to this directory as `spam.csv`.

The file contains:
- Column 1 (v1): Label (ham or spam)
- Column 2 (v2): Text message content

**Files:**

- `spam.csv` - Generated by running the notebook or training script (not committed to git)

Do not commit `spam.csv` to the repository. The dataset will be downloaded fresh when needed.
